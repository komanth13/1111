# SlimTrack 3.4.1 — аккаунты и доступ администратора

## Что готово

BuildConfig.DEBUG больше не выдаёт права администратора. Новый и неподтверждённый пользователь получает Free. Обновление удаляет прежние локальные тестовые тарифы, гостевые разрешения, приглашения и импортированные настройки тарифов; дневник, вес, профиль, каталог продуктов и платёжные реквизиты остаются на устройстве. Тестовый переключатель тарифов удалён из панели.

В коде реализованы Firebase Authentication: Google через Android Credential Manager, email/пароль, подтверждение email, повторная отправка письма, сброс пароля, обновление статуса и выход. Пароли и ID-токены не записываются в собственные настройки приложения и не выводятся в журналы. Авторизационные SharedPreferences исключены из Android Backup. Дневник пока локальный, вход не добавляет облачную синхронизацию или отдельные дневники для нескольких аккаунтов на одном устройстве.

Администратору необходимы одновременно: Firebase UID, подтверждённый email, совпадение с явно настроенным единственным email и булев серверный custom claim `admin=true`. Роль проверяется после онлайн-обновления токена, при возврате в приложение и каждые пять минут. Отсутствие конфигурации, ошибка сети, истёкшая проверка или выход закрывают административный доступ. Вход обычного пользователя не выдаёт платную подписку. Серверная проверка платежей и общая серверная система промокодов пока не подключены; клиентская активация отключена.

## Что ещё нужно подключить

В текущей сборке конфигурация Firebase отсутствует. Доступен Free, административные функции закрыты. Формы входа появляются только после подключения настоящего проекта. Нельзя проверять реальный Google OAuth и отправку писем без проекта и его провайдеров.

1. Создать/выбрать проект Firebase владельца. Зарегистрировать Android app с applicationId `com.aistudio.slimtrack.vwnpzk.stable`.
2. Добавить сертификат нынешней сборки: SHA-1 `9bd654b15aef535a409424456888ffaa61eaf52c`; SHA-256 `3e911258b12157f281e900e571d55442a7f323423ce74fef8de53441ef4acf9c`. При смене подписывающего сертификата добавить новый.
3. В Authentication включить Google и Email/Password. Настроить письма подтверждения и сброса пароля, поддержку и политику паролей. Включить защиту от перечисления email.
4. Скопировать `auth/firebase-client.example.json` в `auth/firebase-client.json`. Заполнить public client identifiers: Firebase `api_key`, Android `app_id`, `project_id`, OAuth **Web** client ID `google_web_client_id` и явно указанный `admin_email`. Это не Android OAuth client ID.
5. Пересобрать APK. Первый вход и регистрация любого аккаунта дают Free. Администратор также сначала входит и подтверждает email.
6. В доверенной среде владельца установить Python `firebase-admin`, настроить Application Default Credentials с правами проекта и выполнить `python3 backend/assign_admin.py --project-id YOUR_PROJECT`. Скрипт выдаёт роль только подтверждённому email из конфигурации и снимает старые административные роли. Приватный ключ/service-account JSON никогда не помещать в APK, публичный git или чат.
7. Нажать «Обновить статус аккаунта» в приложении. Для отзыва выполнить тот же скрипт с `--revoke`.

В будущих удалённых административных endpoint проверять токен на сервере с отзывом и повторно проверять роль (`backend/authorization.py`). Ограничение локального интерфейса не заменяет серверную авторизацию. Сейчас удалённые административные endpoint отсутствуют: панель управляет локальными настройками устройства.

## Проверки

Unit tests покрывают разрешённую роль, неподтверждённый/другой email, отсутствующий claim и конфигурацию, истечение проверки. Robolectric проверяет отсутствие административного доступа даже у debug APK, миграцию старых прав, блокировку привилегированных методов и сохранность дневника. Сборка проверяет Android compilation, существующие тесты штрих-кодов/блюд и подпись APK.

Реальный Google/email вход, доставка письма и выдача/отзыв custom claim требуют финальной проверки после подключения проекта.

Официальные руководства: https://firebase.google.com/docs/auth/android/google-signin ; https://firebase.google.com/docs/auth/android/password-auth ; https://firebase.google.com/docs/auth/admin/custom-claims

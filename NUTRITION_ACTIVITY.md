# SlimTrack 3.5.0 — повседневная активность и расчёт питания

Новый профиль начинается с низкой активности. Описания уровней учитывают ходьбу, домашние дела, работу на ногах, физическую работу и спорт. Можно ввести средние шаги за неделю и активные домашние дела в минутах за день. Пустые поля означают неизвестное значение, ноль — отсутствие нагрузки. Ручной выбор уровня очищает эти поля.

Расчёт: Mifflin–St Jeor по текущему весу → оценка расхода → выбранный дефицит, ограниченный 20% расхода и нижней границей 1200 ккал для женщин / 1500 для мужчин. При достижении целевого веса включается поддержание. Сохранение изменённых параметров тела или активности пересчитывает цели, если пользователь одновременно не редактировал калории/БЖУ вручную. Также доступна отдельная кнопка применения расчёта. Старые дневники и вручную сохранённые цели при установке не перезаписываются; нужно проверить активность и нажать пересчёт.

Белок: 1.6 г × расчётный вес для белка. Этот вес — текущий, либо целевой при наличии цели, с нижней границей по BMI 25 и верхней по текущему весу. Это практическая настройка приложения, а не индивидуальное клиническое назначение. Жиры: около 28% калорий. Углеводы: остаток; округление вниз исключает превышение калорий суммой БЖУ.

Шаги и домашние дела оцениваются по приблизительным диапазонам. Шаги: <3000 → 1.2; 3000–5999 → 1.3; 6000–8999 → 1.4; 9000–11999 → 1.5; ≥12000 → 1.6. Домашние дела: <30 мин → 1.2; 30–59 → 1.3; 60–119 → 1.4; ≥120 → 1.5. Используется максимум двух коэффициентов, а не сумма. Это консервативная эвристика приложения; она не заменяет измерение энергозатрат и не является точной научной формулой калорий по шагам. Внесённые шаги имеют приоритет над прежним выбранным уровнем спорта.

Пример: женщина, 37 лет, 168 см, 105.5 кг, цель 89 кг, 6000 шагов, 45 минут домашних дел, рекомендованный темп: BMR 1759, поддержание 2463, дефицит 493, цель 1970 ккал; белок 142 г, жиры 61 г, углеводы 213 г. При 4000 шагах и 45 мин домашних дел: примерно 1830 ккал. Реальный темп зависит от расхода и соблюдения плана; стартовую оценку сверяют с трендом веса за 2–3 недели.

Room v3 → v4 добавляет две nullable колонки, сохраняя профиль, дневник и вес. Тесты проверяют точный контрольный пример, дефицит, достигнутую цель, БЖУ, границы активности, ноль/неизвестное значение, валидацию и сохранность данных при обновлении с проверкой схемы Room.
